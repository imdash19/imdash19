<summary><b>🔥 &nbsp;My Consistency Philosophy &amp; Streak Strategy</b></summary>
<br/>

> **⚠️ About Streak Counters**
>
> Standard GitHub streak APIs reset the count even for a **single missed day** —
> which doesn't reflect a developer's true commitment.
>
> **My approach:** I focus on **total contributions**, **contribution density**, and
> **weekly consistency** rather than a raw daily streak number.
>
> 💡 *"Consistency over perfection — 6 out of 7 days every week beats any fragile streak."*

<br/>

| Metric | Target | Status |
|:---|:---:|:---:|
| 🟩 Contributions per week | 5–7 days | 🔥 Active |
| 📅 Monthly consistency | ≥ 25 days / month | ✅ On track |
| 🔁 Annual contributions | Growing | 📈 In progress |
| ⚡ Longest streak | See streak card above | 🎯 Building |
